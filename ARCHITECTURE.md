# Architecture (stable facts; update when they change)

**What:** Tavern Landing, the front page of "the Unassuming Tavern". A single static page: a pixel-art tavern floor, a hanging title sign, and three buttons ("Poly Runner", "Bloodsoup Hell", "Lifebrained") that open the three apps on their own subdomains. Static, no build step, no framework, no backend, no saved data.

## Files
- `index.html`: shell; the sign (`h1`), an empty `#doors` list, the toast and version label. Loads `config.js` then `app.js`.
- `config.js`: `window.TAVERN_CONFIG` with `domain` and, per site, `id`, `label`, `icon`, `subdomain`, `githubPage`. The only file to edit to wire up links. All address fields are blank until Ricky supplies them.
- `app.js`: all logic, plain JS (~150 lines). Sections: sprites (ASCII maps drawn as SVG rects), doors (links from config), toast, scene (torches, floor scale), boot. `APP_VERSION` lives here.
- `style.css`: palette as CSS variables (orange, teal, ink, wood), floor background, sign, stepped-corner buttons, torches, toast.
- `assets/floor.png`: 384x384 floor, generated by `tools/make_floor.py` (seeded, repeatable). `fitFloor()` in `app.js` sets `--floor-size` to a whole-number multiple so art pixels stay square.
- `assets/fonts/`: Press Start 2P (titles, buttons) and VT323 (toast, version), woff2, with their OFL licenses.
- `favicon.svg`: pixel mug.
- `tools/make_floor.py`: needs Pillow and numpy.
- `CNAME`: (added later) the custom domain, one line, nothing else.

## Links
Per door, in `doorUrl()`: `domain` + `subdomain` -> `https://<subdomain>.<domain>/` (a subdomain containing a dot is used as a full host). Else `githubPage` if set. Else the door is locked: the button shows and says the door is barred. Only `https:` URLs are accepted.

## Deploy
GitHub Pages serves `main` from the repo root, with the custom domain set in Settings > Pages and in `CNAME`. Each app repo has its own Pages site on its own subdomain (CNAME record to `<github-name>.github.io`). `.github/workflows/release.yml` publishes a `vN` release (N = `APP_VERSION`) with a zip of the site on every non-docs push to `main`; the zip is an archive copy. Branches: `next` (all agent work), `main` (published versions). Release steps are in CLAUDE.md.

## Run and test
Open `index.html` through any static server (`python3 -m http.server`). No test folder; the quick check is in CLAUDE.md.
